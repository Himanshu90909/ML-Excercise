# Deep Learning Course - GeeksforGeeks DS-16

This repository contains comprehensive Jupyter notebook implementations covering the complete Deep Learning curriculum.

## Course Contents

### Module 1: Neural Network Fundamentals
- `01_nn_basics.ipynb` - Perceptron, Activation Functions, Forward/Backpropagation

### Module 2: Optimization
- `02_gradient_descent_optimizers.ipynb` - Gradient Descent, SGD, Adam, Learning Rate Schedules

### Module 3: MLP & Regularization
- `03_mlp_regularization.ipynb` - Multi-Layer Perceptron, Dropout, Batch Norm, Early Stopping

### Module 4: Convolutional Neural Networks
- `04_cnn.ipynb` - CNN Architecture, LeNet, VGG, ResNet, Transfer Learning, Grad-CAM

### Module 5: Recurrent Neural Networks
- `05_rnn_lstm.ipynb` - RNN, LSTM, GRU, Text Generation, Sentiment Analysis, Time Series

### Module 6: Advanced Topics & Deployment
- `06_deployment_advanced.ipynb` - Model Saving, Transfer Learning, Autoencoders, GANs, Deployment

## Requirements

## Topics Covered
- Perceptron & Neural Network Basics
- Activation Functions (Sigmoid, ReLU, Tanh, Softmax)
- Forward & Backpropagation
- Gradient Descent & Optimizers (SGD, Adam, RMSprop)
- Multi-Layer Perceptron (MLP)
- Regularization (Dropout, Batch Normalization, L1/L2)
- Convolutional Neural Networks (CNN)
- Popular Architectures (LeNet, VGG, ResNet)
- Transfer Learning
- Recurrent Neural Networks (RNN, LSTM, GRU)
- Autoencoders & Variational Autoencoders
- Generative Adversarial Networks (GANs)
- Model Deployment (Flask, Streamlit, TF-Lite)
