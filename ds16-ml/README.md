# Machine Learning Course - GeeksforGeeks DS-16

This repository contains comprehensive Jupyter notebook implementations covering the complete Machine Learning curriculum from the GeeksforGeeks Data Science course.

## Course Contents

### Module 1: Data Preprocessing & EDA
- `01_data_preprocessing.ipynb` - Data cleaning, feature scaling, feature engineering, EDA

### Module 2: Supervised Learning
- `02_regression.ipynb` - Linear Regression, Logistic Regression
- `03_trees_and_ensembles.ipynb` - Decision Trees, Random Forest, Ensemble Learning
- `04_svm_knn_nb.ipynb` - SVM, KNN, Naive Bayes

### Module 3: Unsupervised Learning
- `05_unsupervised_learning.ipynb` - K-Means, Hierarchical Clustering, DBSCAN, PCA, Apriori

### Module 4: Model Evaluation & Tuning
- `06_model_evaluation.ipynb` - Evaluation Metrics, Cross-Validation, Hyperparameter Tuning, Regularization

## Requirements
```
pip install numpy pandas scikit-learn matplotlib seaborn
```

## Topics Covered
- Data Preprocessing & Feature Engineering
- Linear & Logistic Regression
- Decision Trees & Random Forest
- Ensemble Learning (Bagging & Boosting)
- SVM, KNN, Naive Bayes
- K-Means, Hierarchical & DBSCAN Clustering
- PCA & Dimensionality Reduction
- Association Rules (Apriori)
- Model Evaluation (Confusion Matrix, ROC-AUC, F1-Score)
- Cross-Validation & Hyperparameter Tuning
- Regularization (L1, L2, ElasticNet)
- Bias-Variance Tradeoff
